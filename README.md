# Kükenhof

Einseitige Website für den **Kükenhof** — Verkauf frischer, handaufgezogener Küken. Statisches HTML mit Produktkarten, Kontaktformular und 3D-Kartenflip für Charakterzüge.

## Live-Seite

[https://matthiassuetterlin.github.io/Kuekenhof/](https://matthiassuetterlin.github.io/Kuekenhof/)

## Technik

- Eine Datei: `index.html` (HTML, CSS, keine Build-Tools)
- Hosting: GitHub Pages (`main`, Ordner `/`)

## Lokal ansehen

Datei `index.html` im Browser öffnen, oder im Repo-Ordner:

```bash
# optionaler lokaler Server
python3 -m http.server 8000
```

Dann [http://localhost:8000](http://localhost:8000) öffnen.
